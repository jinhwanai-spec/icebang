# 얼음땡 프로토타입 v0.6 (Godot 4.4)

## 실행 방법
1. Godot 4.4 이상을 설치합니다. (godotengine.org → Download, 일반 버전. .NET 버전 아님)
2. Godot를 열고 **가져오기(Import)** → 이 폴더의 `project.godot` 선택
3. 오른쪽 위 ▶(F5)를 누르면 메뉴부터 시작합니다. **헤드셋 착용 추천!**

> 처음 열 때 잠깐 "임포트 중"이 뜨는 건 정상입니다. 게임 시작 직후 1~2초는 맵을 만드는 시간이에요.

- **풀숲**: 들어가면 술래가 아주 가까이 와야만 볼 수 있어요.

## 한 판의 흐름 (v0.7)
1. 봉인석을 모두 가동하면 **탈출 단계**: 맵 가장자리에 탈출구 2곳(초록 빛기둥)이 열리고 3분 안에 나가야 해요.
   - 술래는 바로 폭주하고, 시작할 때 한 번 + 10초마다 생존자 위치를 알아요.
   - 한 명이라도 나가면 클리어. 시간 안에 못 나간 사람, 얼음 상태로 남은 사람은 탈락.
   - 탈출 단계에서는 얼음 제한이 없어요.
2. **얼음 규칙**: 얼음은 무제한이지만, 한 판에 4번째 얼음부터는 1분 안에 땡을 못 받으면 얼음이 깨지고 탈락.
3. **폭주**: 판 시작 10분 뒤(또는 탈출 단계) 모든 술래 공격 속도 +30%, 이동속도 +15%.
4. **술래 순서 (스테이지마다 1마리)**: 쥐 → 유령 → 도살자 → 인형사 → 케르베로스 → 거미 여왕 → 내일부터 다이어트 → 사이코 → 처형인 → 마네킹 → 안개 마녀.
   11스테이지(안개 마녀)를 깨면 **게임 클리어**. 지면 스테이지 1부터 다시.
6. **4인 게임**: 나 + 동료 봇 3명.
7. **스태미나**: 달리면 줄어듦 (꽉 차면 약 20초), 구르기 20 소모. 0이 되면 30까지 찰 때까지 못 달리고 숨소리가 들림.
8. **술래 시야 (두 단계)**: 앞쪽 부채꼴(90°) 4m 안은 바로 알아챔, 12m까지는 1.5초 동안 계속 보여야 알아챔(머리 위 ? 가 진해짐).
9. **탈출구**는 멀리서 안 보여요. 가까이(8m) 가야 글씨가 보이고, 20m 안에서 바람 새는 소리가 들려요.
5. **결과 화면**: 생존자마다 땡 횟수, 봉인석 기여, 공격 회피, 생존 시간, 탈출 여부 + MVP.

- **술래 AI**: 놓치면 도망가던 방향을 예측해서 쫓고, 근처 풀숲을 뒤지고, 가동 중인 봉인석을 지키고, 다른 술래가 쫓는 생존자를 앞질러 막아요.
- **공격 모션**: 술래는 잡기 전에 0.08초 동안 팔을 휘둘러요(술래마다 다른 공격 소리). 그 사이에 구르면 피할 수 있어요.
- **속도**: 술래 추격 속도 = 유저 달리기 속도 × 1.375 (37.5% 빠름). 스테이지가 올라도 빨라지지 않아요. 스킬·패시브는 예외.
- **부활 알림**: 누군가 땡으로 살아나면 모든 술래가 그 위치로 몰려와요.

- **피 흘림**: 바닥에 핏자국이 남고, 술래가 위치를 알고 따라옵니다.
- **얼음은 무조건 무적**: 잡기, 쇠사슬, 도끼, 쥐, 플라스크 모두 안 통해요.

## 봉인석 미니게임
봉인석 앞에서 E를 누르면 미니게임이 뜹니다. **3번 클리어하면 봉인석 가동 완료. 봉인석 4개를 모두 가동하면 클리어.**
- 숨은 글자 찾기(35칸) / 순서 기억(5~6개) / 타이밍 맞추기(Space 2번 연속) / 부적 맞추기(가짜 조각 2개) 중 랜덤
- 봉인석의 단계가 오를수록 조금씩 어려워짐
- 제한 시간 10초, 실패하면 큰 소리가 나서 술래가 옴
- 미니게임 중에도 술래는 움직여요. Esc로 언제든 그만둘 수 있고 진행도는 유지
- 동료 봇은 한 단계당 6초가 지나면 자동 클리어

## 공포 연출
손전등(보는 방향만 밝음), 필름 노이즈, 술래가 가까울수록 빨라지는 심장 소리와 붉게 조여오는 화면, 깜빡이는 가로등·간판, 낮게 깔리는 불길한 소리와 가끔 들리는 쇠 긁는 소리·속삭임. 세기는 `balance.cfg`의 `[horror]`에서 조절해요.

## 숫자 바꾸기 (밸런스 조절)
`balance.cfg`를 메모장이나 Godot에서 열어 숫자만 바꾸세요.
시야(안개 진하기, 술래 시야각), 카메라 거리, 발소리 거리, 땡 시간, 캐릭터별 쿨타임 등이 모두 여기 있습니다.

테스트할 때는 메뉴의 **"테스트용 +100 코인"** 버튼으로 공통 능력을 바로 해금할 수 있어요.
출시 전에는 `balance.cfg`의 `[debug]`를 모두 `false`로 바꾸세요.

## 씬 구조 (노드 트리)

**menu.tscn** — 메인 메뉴 + 상점 + 캐릭터 선택 (UI는 menu.gd가 코드로 만듦)

**main.tscn** — 게임 한 판
```
Main (Node3D)  ← main.gd
├─ WorldEnvironment        밤하늘, 짙은 안개(시야 제한), 그림자, 빛번짐
├─ Moon (DirectionalLight3D)
├─ HUD (CanvasLayer)  ← hud.gd   글자, 쿨타임, 해동 게이지, 화면 효과, 창
└─ (게임 시작 시 추가)
   ├─ Level (NavigationRegion3D)   level_builder.gd가 도시를 만듦
   │   ├─ 건물/도로/자동차/버스/가로등/나무 (StaticBody3D)
   │   ├─ GrassPatch × 여러 개      풀숲 (Area3D + MultiMesh)
   │   └─ Generator × 3            봉인석
   ├─ Player
   ├─ Ally1, Ally2                 동료 봇
   └─ Seeker                       술래
```

**player.tscn / ally.tscn** — 생존자
```
Player (CharacterBody3D)  ← player.gd (survivor.gd를 물려받음)
├─ Collision, Body (clay_body.gd), Ice, EmoteLabel
├─ Footstep (AudioStreamPlayer3D)   발소리
├─ Sfx (AudioStreamPlayer3D)        얼음/해동/능력 효과음
└─ CameraPivot (Node3D, 눈높이)      좌우 회전
    └─ SpringArm3D (어깨 옆)         위아래 회전, 벽에 카메라가 박히지 않게
        └─ Camera3D
```
ally.tscn은 카메라 대신 `NavigationAgent3D`(길 찾기)가 있습니다.

**seeker.tscn** — 술래 (main.gd가 3종 스크립트 중 하나로 바꿔 끼움)
```
Seeker (CharacterBody3D)  ← seeker_ghost.gd / seeker_butcher.gd / seeker_rat.gd
├─ Collision, Body (seeker_body.gd)
├─ StateLabel (Label3D)        ? ! ... 표시 (가까이 있을 때만 보임)
├─ RevealLabel (Label3D)       카메라에 찍혔을 때 벽 너머로 보이는 표시
├─ Footstep (AudioStreamPlayer3D)   무거운 발소리
└─ NavigationAgent3D
```

**generator.tscn** — 봉인석 미션

## 맵 바꾸기
- `main.gd`의 `MAP_SEED` 숫자를 바꾸면 다른 모양의 도시가 만들어집니다.
- `level_builder.gd` 위쪽 상수(도로 위치, 공원/공터 개수 등)로 구조를 바꿀 수 있어요.
- 3D 에셋을 구하면 `_building`, `_car`, `_bus`, `_tree` 함수 안의 상자를 모델로 바꾸면 됩니다.

## 내보내기(Export) 할 때 주의
`balance.cfg`가 게임에 포함되도록 내보내기 설정 → Resources 탭 →
"리소스가 아닌 파일 내보내기 필터"에 `*.cfg`를 추가하세요.

## 알려진 한계
- 캐릭터는 도형으로 만든 점토 인형, 건물은 질감 입힌 상자입니다. 나중에 모델로 교체하려면 `clay_body.gd`, `seeker_body.gd`, `level_builder.gd`의 해당 부분만 바꾸면 돼요.
- 싱글플레이 + 봇 동료만 있습니다. 멀티플레이는 로드맵 3단계.
- 봇은 고유 능력을 직접 쓰지 않고 패시브만 적용됩니다.

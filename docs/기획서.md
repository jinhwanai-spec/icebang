# 얼음땡: 봉인의 밤 — 게임 디자인 문서 (GDD v0.3)

> 가제입니다. 프로토타입 기준 문서이며, ★ 표시는 아직 결정이 필요한 항목입니다.

## 1. 한 줄 소개

소리를 듣고 움직이는 술래를 피해, 1~4명이 협동해서 봉인석 3개를 가동하는 3D 얼음땡 게임.
위험할 땐 **얼음**으로 버티고, 얼어 있는 동료는 **땡**으로 구한다.

## 2. 코어 루프

```
[메뉴/상점] → [스테이지 시작] → 숨기·이동 → 봉인석 가동(소리 남!) → 술래 접근
     ↑                                ↑                                │
     │                                └──── 땡으로 동료 구출 ← 얼음 ←─┘
     │
[코인 정산] ← 클리어(봉인석 3개) 또는 패배
     │
     └→ 코인으로 얼음 상태 능력 해금 → 다음 판
```

한 판 목표 시간: 6~10분.

## 3. 규칙

| 항목 | 내용 |
|---|---|
| 술래 | 소리를 듣고 그 위치로 이동. 시야는 5m, 앞쪽 64°로 좁음. 1.8m 안은 등 뒤도 감지 |
| 유저 시야 | 밤 + 짙은 안개로 20m 앞이 거의 안 보임. 눈높이 어깨 시점 |
| 소리 | 유저·술래 모두 걸으면 3D 발소리. 헤드셋으로 위치 파악. 소리 범위 표시는 없음 (추후 캐릭터 능력) |
| 풀숲 | 들어가면 술래가 2m 안까지 와야 보임 |
| 잡힘 | 움직일 수 있는(얼음이 아닌) 생존자가 술래에 닿으면 탈락 |
| 얼음 | 언제든 사용. 못 움직이지만 잡히지 않음. 스스로 못 풂 |
| 땡 | 다른 생존자가 1.8m 안에 10초 붙어 있으면 풀림. 떨어지면 처음부터 (사나이는 즉시) |
| 미션 | 봉인석 3개 가동 → 술래 봉인 → 스테이지 클리어 |
| 패배 | 전원 탈락, 또는 살아있는 전원이 얼음 상태 |

### 소리의 크기 (술래가 듣는 거리)

| 행동 | 거리 |
|---|---|
| 살금살금(Ctrl) | 2m (아주 작음, 대신 느림) |
| 걷기 | 9m |
| 달리기(Shift) | 22m |
| 봉인석 가동 | 2초마다 20m |
| 소리 내기 능력 | 18m (원하는 위치) |

이 구조 덕분에 "빨리 갈까, 조용히 갈까", "지금 봉인석을 돌려도 될까"를 계속 고민하게 됩니다.

## 5. 밸런스 장치 제안

### 얼음 남용 방지
- **(프로토타입에 적용)** 땡으로 풀린 뒤 3초간 다시 얼음 불가 → "풀리자마자 또 얼음" 방지
- 패배 조건(전원 얼음 = 패배)이 가장 강한 장치. 다 같이 얼면 진다
- ★ 추가 후보 A: 얼음 상태로 60초가 지나면 "동상" — 탈락 (긴장감↑, 초보자 부담↑)
- ★ 추가 후보 B: 한 판당 얼음 횟수 제한 (예: 5회)
- ★ 추가 후보 C: 얼음이 오래될수록 술래가 그 위치를 "느끼게" 됨 (얼음 위치가 점점 노출)

### 술래 캠핑 대응
- 캠핑 시간을 3.5초로 짧게 제한, 끝나면 반드시 순찰로 돌아감
- 캠핑 중 땡하러 다가온 생존자는 바로 발견됨 → 구출에도 위험이 따름
- **소리 내기 능력이 캠핑의 정답**: 얼음 상태 플레이어가 소리로 술래를 끌어내면 동료가 구하러 옴

### 소리 내기 능력
- 쿨타임 100초로 한 판에 3~5번 정도만 쓸 수 있음
- 얼음 상태에서만 사용 → 쓰려면 얼음이라는 위험을 감수해야 함
- 너무 강하면: 쿨타임 증가, 소리 거리 감소 / 너무 약하면: 술래가 소리 위치에서 더 오래 수색

### 인원수별 난이도 (멀티플레이 단계에서 적용)
| 인원 | 봉인석 가동 시간 | 술래 속도 | 비고 |
|---|---|---|---|
| 1명(+봇) | 12초 | 100% | 봇 동료 2명 |
| 2명 | 14초 | 100% | |
| 3명 | 16초 | 105% | |
| 4명 | 18초 | 110% | ★ 술래 2마리 옵션 |

## 6. 미션 아이디어 (AI를 무찌르는 미션)

| # | 이름 | 내용 | 특징 |
|---|---|---|---|
| 1 | 봉인석 가동 **(구현됨)** | 근처에서 E를 누르고 있기 | 소리가 나서 위험 |
| 2 | 부적 모으기 | 맵 곳곳의 부적 5장 수집 후 제단에 바치기 | 이동량 많음 |
| 3 | 종 울리기 | 큰 소리가 나는 종을 쳐서 술래를 3초 기절 | 일부러 소리를 내야 함 |
| 4 | 약점 노출 | 술래 등 뒤의 빛나는 약점을 몰래 터치 | 가장 짜릿함 |
| 5 | 2인 동시 레버 | 멀리 떨어진 레버 2개를 동시에 당기기 | 협동 강제 |
| 6 | 등불 지키기 | 등불을 들고 목적지까지 운반(들고 있으면 느림) | 호위형 |
| 7 | 거울 함정 | 거울 3개를 돌려 빛으로 술래를 비추기 | 퍼즐형 |
| 8 | 얼음 동료의 미션 | 얼음 상태일 때만 보이는 숨은 문양 찾기 | 얼음에 이점 부여 |

스테이지마다 이 중 3개가 섞여 나오게 하면 판마다 다른 경험이 됩니다.

| 공간을 지배하는 자 | 랜덤 위치로 순간이동. 쿨 60초 | 고른 동료를 내 앞으로 소환. 얼음 상태면 얼음 유지. 쿨 75초 |

## 7-1. 술래 (매 판 랜덤, 유저에게 알려주지 않음)

| 술래 | 능력 1 | 능력 2 |
|---|---|---|
| 유령 | (패시브) 벽 통과. 벽 속에 있는 동안 안 보임 | 대쉬: 멈춰서 1.5초 노려본 뒤 약 12m 돌진. 돌진 중 닿으면 잡힘. 쿨 30초 |
| 도살자 | 쇠사슬 그랩: 약 10m, 판정 좁음. 맞으면 2m 앞까지 끌려옴 (그 뒤 0.8초 도망칠 틈). 쿨 40초 | 도끼 던지기: 약 10m, 느리게 날아감, 판정 넉넉함. 맞으면 15초 피 흘림 + 이동속도 50% 감소. 쿨 30초 |
| 역병의 쥐 | 쥐 소환: 1마리, 30초간 수색. 물리면 15초 피 흘림(죽지 않음). E로 잡으면 술래가 그 위치를 앎. 쿨 50초 | 플라스크: 반경 3m, 40% 감속, 8초. 최대 3개, 15초마다 1개 충전 |

- 피 흘림: 핏자국이 남고 술래가 35m 안에서 위치를 알고 따라옴
- 얼음은 무조건 무적 (잡기, 모든 술래 능력 무효)

| 소리 내기 **(구현됨)** | 조준한 곳에 소리 → 술래 유인. 쿨타임 100초 | 100 |

## 8. 성장 시스템과 재화

| 획득 | 코인 |
|---|---|
| 봉인석 1개 가동 | 10 |
| 땡으로 동료 구출 1회 | 5 |
| 스테이지 클리어 | 50 |

- 진 판에서도 한 만큼은 받음 → "한 판만 더" 동기
- 평균 패배 판 ≈ 20~30코인, 클리어 판 ≈ 90~100코인
- 첫 능력(이모티콘 50)은 1~2판, 핵심 능력(소리 내기 100)은 2~4판 안에 얻도록 설계
- 이후 능력은 150~200 → 판당 성장 체감이 너무 빨리 끝나지 않도록
- ★ 꾸미기(스킨, 이모티콘 종류)를 재화 소비처로 추가할지

## 8-2. 맵

- 100m × 100m 풀이 자란 버려진 도시 거리 (참고 이미지 분위기)
- 바둑판 도로 3×3, 블록 16개: 건물 블록 10, 공원 3, 공터(폐차장) 3
- 봉인석은 공원/공터 6곳 중 3곳 랜덤
- 높은 건물과 골목, 버려진 차와 버스, 가로등(일부 고장), 간판, 풀숲
- 현재는 도형 + 질감. 에셋(유료 Synty POLYGON 계열 등) 구하면 교체

## 9. 스테이지 진행

- 클리어하면 다음 스테이지, 지면 같은 스테이지 재도전
- 스테이지가 오를 때마다 술래 속도 +8%
- 봉인석 위치는 매 판 6곳 중 3곳 랜덤
- 이후 확장: 스테이지 5마다 새 맵(학교 운동장 → 한옥 마을 → 놀이공원 → 폐교), 새 술래 종류
- ★ 로그라이트 방식(실패 시 1스테이지부터)과 현재 방식(실패해도 유지) 중 선택

# 개발 로드맵 (혼자 만드는 초보자 기준)

| 단계 | 기간(예상) | 할 일 | 완료 기준 |
|---|---|---|---|
| 1. 싱글 프로토타입 | 2~4주 | **지금 받은 프로젝트**. 수치 조정하며 재미 확인 | 친구 3명에게 시켜 보고 "한 판 더" 소리가 나오는가 |
| 2. 그레이박스 개선 | 2~3주 | 미션 2~3종 추가, 맵 1개 다듬기, 사운드 효과 | 10분짜리 한 판이 지루하지 않음 |
| 3. 멀티플레이 | 4~8주 | Godot 멀티플레이 API로 LAN 먼저 → GodotSteam으로 친구 초대 | 2명이 인터넷으로 끝까지 한 판 플레이 |
| 4. 콘텐츠 | 6~12주 | 캐릭터·맵 아트, 능력 5종, 맵 3개, 술래 2종 | 3시간 이상 즐길 분량 |
| 5. Steam 준비 | 2~4주 | 스토어 페이지, 트레일러, 데모, 넥스트 페스트 참가 | 위시리스트 모으기 시작 |
| 6. 출시 | — | 버그 수정, 업적, 클라우드 저장 | 출시! |

**초보자 팁**: 3단계(멀티플레이)가 가장 어렵습니다. 그래서 지금 코드는 "생존자(Survivor)" 공통 스크립트와 봇 동료로 나눠 두었어요. 나중에 봇 자리에 다른 유저가 들어가게 바꾸면 됩니다.

# Steam 판매 준비 체크리스트

### 계정과 비용
- Steamworks 파트너 가입 (partner.steamgames.com)
- 게임 1개당 Steam Direct 등록비 100달러 (매출 1,000달러 이상이면 환급) — 금액은 바뀔 수 있으니 가입 시 확인
- 세금·은행 정보 입력 (한국 개인/사업자)

### 기술
- **GodotSteam**: Godot에서 Steam 기능을 쓰게 해주는 애드온 (친구 초대, 로비, 업적, 클라우드)
- 친구 초대: Steam 로비 + Steam 네트워킹(P2P)
- 업적 예시: 첫 클리어, 땡 100회, 얼음 없이 클리어, 소리 내기로 술래 유인 후 동료 구출
- 클라우드 저장: Steamworks 설정의 "Auto-Cloud"에 `save.cfg` 경로 등록 (코드 수정 거의 없음)
- 빌드 업로드: SteamPipe (steamcmd)

### 스토어 페이지
- 캡슐 이미지 여러 사이즈 (메인 캡슐, 작은 캡슐, 헤더 등 — Steamworks 문서의 최신 규격 확인)
- 스크린샷 5장 이상, 트레일러 1개 (첫 5초 안에 "얼음 → 땡" 장면)
- 짧은 설명, 태그(협동, 멀티플레이, 공포, 캐주얼, 파티 게임 등)
- 출시 최소 2주 전 "곧 출시" 페이지 공개 필요 → 실제로는 몇 달 전에 열어 위시리스트를 모으는 게 좋음
- 연령 등급 설문

### 마케팅
- 짧은 플레이 영상(쇼츠/틱톡)이 이런 장르에 가장 효과적
- Steam 넥스트 페스트에 데모로 참가

# 얼음땡 점검 결과 & 수정 시나리오 (10/21, 19:00 마감)

## 점검한 방법
- 맵 4개(도시·숲·학교·병원) AI 자동 대전 각 60초 → 스크립트 오류 0건, 경고 1종(이모트 효과 정리 오류)
- PC(RTX 3060, Forward+) 실제 플레이 화면 21장 캡처 (시작·봉인석·술래 등장·랜덤 위치, 메뉴)
  - 로딩: 도시 3.6초 / 숲 1.4초 / 학교 1.1초 / 병원 1.0초, FPS: 도시 75 · 숲 99 · 학교 150 · 병원 93
- 전체 코드 점검 (캐릭터 11종 능력, 술래 11종, 멀티, HUD, 메뉴, 밸런스 설정)

### 바꾸지 않고 의견만 드리는 것 (직접 정하신 밸런스)
- 카메라맨 쿨 2초 + 스턴 1.5초 → 술래가 75% 시간 동안 스턴 가능. 원하시면 "스턴 후 3초 면역"만 추가 가능
- 마네킹 기습 쿨 2.5초 → 쳐다보기 견제가 거의 안 통함
- 사냥꾼 화살이 판당 술래 수(=1발)만큼만 나옴 → 2~3발 고정 제안
